# 포맷 공통 워크플로

마크다운의 포매팅만 교정한다. 호출 입력이 파일이나 폴더 경로면 그 대상을 사용하고, 없으면 대상을 한 번 확인한다. 폴더는 사용자가 재귀 처리를 명시하지 않는 한 바로 아래 `.md` 파일까지만 처리한다.

## 교정 규칙

- 헤딩 마커 뒤 공백을 하나로 하고 앞뒤 빈 줄을 정리한다. 헤딩 레벨은 바꾸지 않는다.
- 같은 깊이의 불릿을 `-`로 통일하고 2칸 들여쓰기와 블록 앞뒤 빈 줄을 정리한다.
- 연속 빈 줄을 하나로 줄이고 trailing whitespace를 없애며 파일 끝 줄바꿈 하나를 보장한다.
- 인라인 백틱 쌍을 확인하고 fenced code block 앞뒤 빈 줄을 정리한다. 코드 내용과 언어 지정자는 추측해 바꾸지 않는다.
- 표 구분자 주변 공백과 헤더 구분선 형식을 정규화한다.
- 굵기·이탤릭 마커 안쪽의 불필요한 공백을 제거한다.
- YAML frontmatter 구분선, 들여쓰기, 공백만 정규화한다.

문장·단어·의미, 헤딩 레벨, 항목 순서, 코드 내용, wikilink, frontmatter 값은 변경하지 않는다. 내용 보강 요청은 주제정리 워크플로 대상이다.

저장 후 처리 파일별 변경 종류와 건수를 보고하고, 변경 없는 파일은 별도 목록으로 표시한다.

# 메모 공통 워크플로

호출 시 전달된 키워드, 문장, 코드 조각, 링크 등을 빠르게 캡처한다. 입력이 없으면 메모 내용을 한 번 확인한다.

## 분류

- 특정 기술의 명확한 개념이나 질문이면 해당 `topics/` 파일에 append한다.
- 오늘 면접 세션과 직접 관련되면 오늘 `daily/YYYY-MM-DD.md`에 append한다. 파일이 없으면 세션 내용을 추측해 새 daily를 만들지 않고 memo로 저장한다.
- 맥락이 부족하거나 더 정리가 필요하면 `memo/`에 fleeting note로 저장한다.

topics 또는 daily에 추가할 때 기존 내용을 덮어쓰지 않고 중복을 병합한다. 외부 사실을 추가하면 확인 가능한 출처를 포함한다.

memo 파일명은 `YYYYMMDDHHmm-{핵심키워드}.md`이며 형식은 다음과 같다.

```markdown
---
date: YYYY-MM-DD HH:mm
tags: [관련기술]
status: memo
---

# {핵심 키워드}

{캡처한 내용}

---
처리 기한: {오늘부터 7일 후}
이동 후보: topics/{기술명}/
```

저장 위치와 내용을 한 줄로 요약한다.

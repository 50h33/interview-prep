# Memo

> 빠른 캡처 공간. 나중에 분류할 fleeting notes를 여기 던진다.
> Claude Code 혹은 Codex에서 메모를 캡처하고, 마무리 또는 주간회고 시 topics/로 이동.
> Claude Code: `/메모`, `/마무리`, `/주간회고` · Codex: `$prep-memo`, `$prep-wrap-up`, `$prep-weekly`.

---

## 사용 방법

- **바로 기록하고 싶을 때**: 이 폴더에 아무 파일이나 만들어도 됨
- **`/메모` 또는 `$prep-memo` 명령**: 구술하면 자동으로 여기 파일로 저장
- **처리 규칙**: memo 파일은 7일 이내 처리 (topics/ 이동 or 삭제)

## 파일 명명

`YYYYMMDDHHmm-{키워드}.md` 형식 권장
예: `202604011430-kafka-consumer-group.md`

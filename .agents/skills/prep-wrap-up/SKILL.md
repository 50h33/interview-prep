상대 링크는 이 `SKILL.md`가 있는 디렉터리를 기준으로 해석하고, 공통 워크플로의 셸 명령은 vault 루트에서 실행한다.

먼저 [AGENTS.md](../../../AGENTS.md)와 [마무리 공통 워크플로](../../../workflows/wrap-up.md)를 실제로 읽고 모두 따른다. 사용자가 `$prep-wrap-up` 뒤에 제공한 텍스트나 자연어 요청에서 `전체`를 명시했으면 공통 워크플로의 "호출 시 전달된 입력"으로 전달한다.
